Installing the Impactor Placeholders mod is as straightforward as almost any mod! Follow the steps below to get started.

:::note
Impactor Placeholders can be installed in either a server or client environment as long as the requirements are met!
:::

***
## Requirements
Impactor Placeholders requires the following to run (as of March 2026):
- **Minecraft** - 1.21.1
- **Fabric Loader** - 0.17.2+
- **Fabric API** - 0.116.6-1.21.1 (or greater)
- **Java** - 21+
- **Fabric Language Kotlin** - 1.13.0+kotlin.2.1.0 (or greater)
- **Impactor** - 5.3.0 (or greater)
- **Any Supported Placeholder Services**
  - **TextPlaceholderAPI**
  - **MiniPlaceholders**

## Installation Steps
1. Set up a Fabric server/client with Minecraft 1.21.1
2. Install the Impactor Placeholders mod jar into the `mods` folder of your server/game files. Download the mod <a href="https://modrinth.com/mod/impactorplaceholders" target="_blank" rel="noopener noreferrer">here</a>!
3. Download all required dependencies for the mod (See [Requirements](#requirements) above)]
4. Restart the server/client to generate the configuration files and folders.
5. Begin using any of the supported placeholders! See [Placeholders](/impactorplaceholders/getting_started/placeholders/) for available placeholders.
