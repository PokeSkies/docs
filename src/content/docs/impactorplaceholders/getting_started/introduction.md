Welcome to the documentation for the Impactor Placeholders mod! This guide will help you get started with using and configuring the mod.
***

## Quick Start
1. Install the Impactor Placeholders mod jar onto your server. Download the mod <a href="https://modrinth.com/mod/impactorplaceholders" target="_blank" rel="noopener noreferrer">here</a>!
2. Install Impactor and a Placeholder API service mod that Impactor Placeholder supports (e.g. TextPlaceholderAPI, MiniPlaceholders, etc.)
3. Begin using the placeholders in other mods that support placeholders!

## What is Impactor Placeholders?

Impactor Placeholders is a server-sided (or client-sided) fabric mod that adds placeholders based on the Impactor mod! Includes many useful placeholders relating to player economy.
