Welcome to the documentation for the Cobblemon Placeholders mod! This guide will help you get started with using and configuring the mod.
***

## Quick Start
1. Install the Cobblemon Placeholders mod jar onto your server. Download the mod <a href="https://modrinth.com/mod/cobblemonplaceholders" target="_blank" rel="noopener noreferrer">here</a>!
2. Install a Placeholder API service mod that Cobblemon Placeholder supports (e.g. TextPlaceholderAPI, MiniPlaceholders, etc.)
3. Begin using the placeholders in other mods that support placeholders!

## What is Cobblemon Placeholders?

Cobblemon Placeholders is a server-sided (or client-sided) fabric mod that adds placeholders for the Cobblemon mod! Includes many useful placeholders for Pokemon species, player Party Pokemon, the PokeDex, Molang queries, and more.
