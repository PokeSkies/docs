### Dex
`(dex id)` is an optional dex ID that can be provided (ex: `cobblemon:national`)

| MiniPlaceholders                                 | PlaceholderAPI                                | Return Type |
|--------------------------------------------------|-----------------------------------------------|-------------|
| `<cobblemon_pokedex_amount_seen:(dex id)>`       | `%cobblemon:pokedex_amount_seen (dex id)%`    | int         |
| `<cobblemon_pokedex_amount_caught:(dex id)>`     | `%cobblemon:pokedex_amount_caught (dex id)%`  | int         |
| `<cobblemon_pokedex_percent_seen:(dex id)>`      | `%cobblemon:pokedex_percent_seen (dex id)%`   | int         |
| `<cobblemon_pokedex_percent_caught:(dex id)>`    | `%cobblemon:pokedex_percent_caught (dex id)%` | int         |
| `<cobblemon_pokedex_species_seen:(dex id)>`      | `%cobblemon:pokedex_species_seen (dex id)%`   | boolean     |
| `<cobblemon_pokedex_species_caught:(dex id)>`    | `%cobblemon:pokedex_species_caught (dex id)%` | boolean     |
| 🚫 `<cobblemon_pokedex_shinies_seen:(dex id)>`   | `%cobblemon:pokedex_shinies_seen (dex id)%`   | int         |
| 🚫 `<cobblemon_pokedex_shinies_caught:(dex id)>` | `%cobblemon:pokedex_shinies_caught (dex id)%` | int         |

_*🚫 - These placeholders have been removed and are no longer available. They were either working incorrectly or have been replaced.*_

### Misc
- `[expression]` is a molang expression string that will be parsed.

| MiniPlaceholders                            | PlaceholderAPI                           | Return Type |
|---------------------------------------------|------------------------------------------|-------------|
| ⚠️ `<cobblemon_molang_player:[expression]>` | `%cobblemon:molang_player [expression]%` | string      |
| `<cobblemon_pc_box_count>`                  | `%cobblemon:pc_box_count%`               | int         |

_*⚠️ - These placeholders are unsafe and can cause potential security issues. Please see [Unsafe Placeholders](/cobblemonplaceholders/getting_started/unsafe_placeholders/) for more information.*_


## Server Placeholders
These placeholders can be used without any context!
### Species Info
`[species]` is the string name of the species (ex: `pikachu`)

| MiniPlaceholders                                  | PlaceholderAPI                                    | Return Type     |
|---------------------------------------------------|---------------------------------------------------|-----------------|
| `<cobblemon_species_name:[species]>`              | `%cobblemon:species_name [species]%`              | string          |
| `<cobblemon_species_id_national:[species]>`       | `%cobblemon:species_id_national [species]%`       | int             |
| `<cobblemon_species_types:[species]>`             | `%cobblemon:species_types [species]%`             | list of strings |

### Dex
