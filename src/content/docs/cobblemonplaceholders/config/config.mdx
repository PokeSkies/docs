## Options
***
### Debug
Whether to enable debug mode for the mod. Debug mode will print additional information to the console, which can be useful for troubleshooting issues with the mod. Default value is `false`.
```json
"debug": false
```
### Unsafe
:::danger
This feature (as the name implies) can be unsafe if used improperly. Only enable this if you know what you're doing and understand the potential risks.
:::
Enables unsafe placeholders that can cause security issues if used improperly. These placeholders can potentially expose sensitive information or allow for code execution if used in an unsafe way. Default value is `false`.
```json
"unsafe": false
```

### Placeholder Configuration
A set of options for configuring some placeholders that have customizable behavior. These options are categorized into different sections based on the type of placeholders available.
```json
"placeholders": {
  "party": {},
  "species": {},
  "pokedex": {},
  "misc": {}
}
```
