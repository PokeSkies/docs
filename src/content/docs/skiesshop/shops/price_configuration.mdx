## Price Options
### Price (required)
The price to buy/sell this entry for. Any number 0 and below is considered free. The total price for a purchase is this value multiplied by the amount purchased.
```json
"type": "ITEM"
```
### Economy
The economy integration to use for this transaction. A list of supported economies can be found in [Economies](/skiesshop/getting_started/economies/).
```json
"economy": "IMPACTOR"
```

### Currency
The currency to use for this transaction. Not supported for some Economy mods.
```json
"currency": "impactor:dollars"
```
### Name
The name of the currency for the placeholders `%buy_price_currency%` and `%sell_price_currency%`.
```json
"name": "Dollars"
```
### Max Amount
The maximum amount of items that can be bought/sold in one transaction. Any number 0 and below is considered unlimited.
```json
"max_amount": 128
```
### Requirements
Requirements that must be met in order for the player to buy/sell this entry. See [Requirements](/skiesshop/shops/requirements/) for more information.
```json
"requirements": {
  "requirements": {},
  "deny_actions": {},
  "success_actions": {},
  "minimum_requirements": 1,
  "stop_at_success": true,
  "send_denial_message": true
}
```
