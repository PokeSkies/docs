Each Shop configuration is stored in its own JSON file within the `shops` folder inside the main `/config/skiesshops/` folder.
<FileTree>
- config
    - skiesshop
        - shops
            - example_shop.json
            - second_shop.json
</FileTree>

Every Shop has a large set of configuration options to customize the Shop!
```json
{
  "title": "Example Shop",
  "type": "GENERIC_9x6",
  "entry_lore": {},
  "click_options": {},
  "open_actions": {},
  "close_actions": {},
  "entries": {},
  "items": {}
}
```

## Title
The title of the GUI for the shop. Uses <a href="https://docs.advntr.dev/minimessage/format.html" target="_blank" rel="noopener noreferrer">MiniMessage formatting</a>!
```json
"title": "<red>Example Shop"
```
## Type
The type of inventory menu to use.
```json
"type": "GENERIC_9X3"
```

## Entry Lore (optional)
:::note
This is an optional setting that can be left undefined. If undefined, the Entry Lore will be pulled from the global `config.json`
:::
Override the lore lines added to this Shop's Entries. See [Entry Lore](/skieshop/config/entry_lore) for more information on Shop Entry Lore configuration.
```json
"entry_lore": {
  "buy": [
    "%display_item_lore%",
    "",
    "<green><b>Buy Price:</b> <white>%buy_price% %buy_price_currency%",
    "",
    "<red>Left-Click to buy this item"
  ],
  "sell": [
    "%display_item_lore%",
    "",
    "<red><b>Sell Price:</b> <white>%sell_price% %sell_price_currency%",
    "",
    "<red>Right-Click to sell this item"
  ],
  "buy_sell": [
    "%display_item_lore%",
    "",
    "<green><b>Buy Price:</b> <white>%buy_price% %buy_price_currency%",
    "<red><b>Sell Price:</b> <white>%sell_price% %sell_price_currency%",
    "",
    "<red>Left-Click to buy this item",
    "<red>Right-Click to sell this item"
  ]
}
```

## Click Options (optional)
:::note
This is an optional setting that can be left undefined. If undefined, the Click Options will be pulled from the global `config.json`
:::
Override the click behavior of all shop entries in this Shop. See [Click Options](/skieshop/config/click_options) for more information on Shop Click Options configuration.
```json
"click_options": {
  "ANY_CLICK": {
    "type": "OPEN_CONFIRM_MENU",
    "sound": {
      "id": "minecraft:ui.button.click",
      "source": "MASTER",
      "volume": 0.5,
      "pitch": 1.0
    },
    "transactions": [
      "buy"
    ],
    "menu": "example_buy"
  }
}
```

## Open Actions
A list of Actions that are executed when the Shop GUI is opened. Importantly, Open Actions are only executed when opening the Shop, not from something like a `BACK` action behavior. See [Actions](/skiesshop/shops/actions/) for more information on actions.
```json
"open_actions": {
  "action_1": {
    "type": "COMMAND_CONSOLE",
    "click": "ANY",
    "commands": ["give %player% diamond 1"]
  },
  "action_2": {
    "type": "MESSAGE",
    "click": "ANY",
    "message": ["<blue>Thanks for opening my menu!"]
  }
}
```

## Close Actions
A list of Actions that are executed when the Shop GUI is closed. Importantly, Close Actions do not execute when opening a Confirm Menu. See [Actions](/skiesshop/shops/actions/) for more information on actions.
```json
"open_actions": {
  "action_1": {
    "type": "COMMAND_CONSOLE",
    "click": "ANY",
    "commands": ["give %player% diamond 1"]
  },
  "action_2": {
    "type": "MESSAGE",
    "click": "ANY",
    "message": ["<blue>Thanks for opening my menu!"]

}
```

## Entries
A list of Shop entries that can appear inside a shop for the player. Each entry in the list is a MAP (key, value pair) entry of ID with a Shop Entry defined. There are multiple types of Shop Entries, each type has some shared and unique settings.
```json
"entries": {
  "dirt": {
    "type": "ITEM",
    "slot": 0,
    "page": [
      1
    ],
    "item": "minecraft:dirt",
    "buy": {
      "price": 1,
      "economy": "IMPACTOR",
      "currency": "impactor:dollars"
    },
    "sell": {
      "price": 1,
      "economy": "IMPACTOR",
      "currency": "impactor:dollars"
    }
  }
}
```

## Items
A list of additional items to be displayed in the Shop's GUI. Each item in the list is a MAP (key, value pair) entry of ID with item options. These items cannot be bought and are used for decoration or action purposes (like pagination, category UIs, etc.).
```json
"static": {
  "background": {
    "item": "minecraft:black_stained_glass_pane",
    "slots": [
      45, 46, 47, 48, 49, 50, 51, 52, 53
    ]
  },
  "back": {
    "item": "minecraft:barrier",
    "slot": 45,
    "name": "<red>Back to Categories",
    "lore": [
      "<gray>Click to go back to the categories"
    ],
    "actions": {
      "open_shop": {
        "type": "OPEN_SHOP",
        "id": "example_categories"
      }
    }
  }
}
```
