## Entry Options
### Type (required)
The type of shop entry that this is. A list of types can be found in [Entry Types](#entry-types).
```json
"type": "ITEM"
```
### Display (required)
The item used to represent the reward in the GUI. If `ITEM` type, this does not affect the item given to/taken from the player.
```json
"display": {
  "item": "minecraft:diamond",
  "name": "<aqua>Diamond",
  "lore": [
    "<gray>This is a special diamond!"
  ]
}
```
### Slots
> Aliases: `slot`

A list of slots that this item will be inserted into. This value should be between `0` and the max slots in the GUI type used. If empty, an available open slot will automatically be found. If no slot is found, the item will not be included. Defaults to an empty list if not provided.
:::tip
Some options are flexible-lists, meaning you can either set it to a specific value or define a list!
> `"slots": 1`<br></br>
> `"slots": [1, 2, 3]`
:::
```json
"slots": [0, 1, 7, 8]
```
### Pages
> Aliases: `page`

A list of pages that this item will be placed into at the slot specified. The first page is 1. Defaults to `[1]` if not provided.
:::tip
Some options are flexible-lists, meaning you can either set it to a specific value or define a list!
> `"pages": 1`<br></br>
> `"pages": [1, 2, 3]`
:::
```json
"pages": [1, 2]
```
### Buy
Options for buying this item. If not defined, this entry cannot be bought.
```json
"buy": {
  "price": 1,
  "economy": "IMPACTOR",
  "currency": "impactor:dollars",
  "name": "Dollars",
  "max_amount": 128,
  "requirements": {}
}
```

## Entry Lore (optional)
:::note
This is an optional setting that can be left undefined. If undefined, the Entry Lore will be pulled first from the Shop's Entry Lore, then the global `config.json`
:::
Override the lore for this specific Shop Entry. See [Entry Lore](/skieshop/config/entry_lore) for more information on Shop Entry Lore configuration.
```json
"entry_lore": [
  "%display_item_lore%",
  "",
  "<green><b>Buy Price:</b> <white>%buy_price% %buy_price_currency%",
  "<red><b>Sell Price:</b> <white>%sell_price% %sell_price_currency%",
  "",
  "<red>Left-Click to buy this item",
  "<red>Right-Click to sell this item"
]
```

## Click Options (optional)
:::note
This is an optional setting that can be left undefined. If undefined, the Click Options will be pulled first from the Shop's Click Options, then the global `config.json`
:::
Override the click behavior of this specific Shop Entry. See [Click Options](/skieshop/config/click_options) for more information on Shop Click Options configuration.
```json
"click_options": {
  "ANY_CLICK": {
    "type": "OPEN_CONFIRM_MENU",
    "sound": {
      "id": "minecraft:ui.button.click",
      "source": "MASTER",
      "volume": 0.5,
      "pitch": 1.0
    },
    "transactions": [
      "buy"
    ],
    "menu": "example_buy"
  }
}
```
