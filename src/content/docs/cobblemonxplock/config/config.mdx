## Options
***
### Debug
Whether to enable debug mode for the mod. Debug mode will print additional information to the console, which can be useful for troubleshooting issues with the mod. Default value is `false`.
```json
"debug": false
```
### Id
The unique identifier used to apply lock data to a Pokemon.You can use any string as an identifier, but leaving this as the default value is recommended. This is a useful config option for backwards compatibility with older locking mods!
```json
"id": "XPLock"
```
### Messages
A set of customizable messages that are sent to the player when performing certain actions with the mod. Each message supports <a href="https://docs.advntr.dev/minimessage/format.html" target="_blank" rel="noopener noreferrer">MiniMessage formatting</a>!
```json
"messages": {
  "invalid_slot": "<red>The slot %slot% is invalid! Please choose a slot between 1 and 6.",
  "empty_slot": "<red>The slot %slot% is empty! Please enter a party slot that contains a Pokemon.",
  "locked_xp": "<red>Locked experience for %pokemon% in slot %slot%!",
  "unlocked_xp": "<green>Unlocked experience for %pokemon% in slot %slot%!"
}
```
