## Commands
| Command        | Description                                                        | Permission            |
|----------------|--------------------------------------------------------------------|-----------------------|
| /xplock <slot> | Lock/unlock XP gaining for the Pokemon in the specified party slot | xplock.command.base   |
| /xplock reload | Reload the Mod                                                     | xplock.command.reload |
| /xplock debug  | Toggle the debug mode for more insight into errors                 | xplock.command.debug  |
