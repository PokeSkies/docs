## Commands
| Command        | Description                                                        | Permission                     |
|----------------|--------------------------------------------------------------------|--------------------------------|
| /xplock <slot> | Lock/unlock XP gaining for the Pokemon in the specified party slot | cobblemonxplock.command.base   |
| /xplock reload | Reload the Mod                                                     | cobblemonxplock.command.reload |
| /xplock debug  | Toggle the debug mode for more insight into errors                 | cobblemonxplock.command.debug  |
